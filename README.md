# Sito Floricoltura Lagomarsino

Sito vetrina del vivaio e dei negozi (Nervi, Albaro, Recco).

- `index.html`: la pagina. Dati di negozi, orari, numeri WhatsApp e link social sono nel blocco `CONFIG` all'inizio dello script.
- `media/`: foto, logo e video.

Pubblicato con GitHub Pages dal ramo `main`.
